# ani-search

Утилита для поиска в разных платформах связанных с аниме.

# Возможности

- Поиск в Shikimori и Kodik
- Выдача ответов в JSON формате

# Планы развития:

- `v0.1.0`:
  - Поддержка Shikimori:
    - Поиск по запросу
    - Поиск определённого аниме по Shikimori ID
  - Поддержка Kodik:
    - Поиск по Shikimori ID
    - Резолвинг ссылок на плеер
- `будущие версии`:
  - Возможность использовать как Rust библиотеку
